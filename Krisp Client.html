Questions, answered

Which Minecraft version does it support?

Krisp Client is built for Minecraft 1.21.11 on Fabric. You need Fabric Loader 0.16 or newer, Fabric API and Java 21.

Do I need to install anything on the server?

No. It is a client-side mod, so everything runs on your own game.

Can I move the HUD panels?

Yes. Open the HUD editor from the menu, drag each panel where you want it, and your layout is saved for next time.

Does it work on DonutSMP?

It has a DonutSMP category and a Macro category made for it, with tools like the auction house sniper, auto sell, order dropper and panic pay.

Can I use it on any server?

Servers set their own rules about client mods. Check the rules of a server before you turn modules on there.

Up and running in three steps

  1. Install FabricInstall Fabric Loader 0.16 or newer for Minecraft 1.21.11 with Java 21, then add Fabric API.
  2. Add the jarDrop Krisp_Client.jar into your .minecraft/mods folder next to Fabric API.
  3. Launch and playStart the game and toggle modules from the in-game menu.
